MySQL 8.0.16+; recomendado 8.4. En MySQL Workbench o cliente mysql, ejecutar 01, luego 02 y 03. 01 usa CREATE DATABASE (requiere permisos), InnoDB, utf8mb4_bin y dos triggers con DELIMITER para evitar autoconexiones. Algunos editores SQL tratan DELIMITER como comando del cliente: ejecutar esos bloques con modo script de Workbench, no sentencia individual. Mantener la sesion UTC; los DATETIME no almacenan zona horaria. No se verifico un servidor MySQL durante la preparacion de esta entrega.
